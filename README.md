# Portofolio Pribadi

Situs portofolio satu halaman untuk M. Nur Hidayat — perkenalan diri, keahlian, project unggulan, dan jalur kontak. Dibangun dengan animasi Framer Motion dan desain responsif.

**Live demo:** https://portofolio-phi-ten-33.vercel.app

## ✨ Fitur

- Satu halaman dengan navigasi anchor: About, Skills, Projects, Contact
- Animasi scroll & transisi halus memakai Framer Motion
- Berisi project: car rental, portal desa/UMKM, aplikasi keuangan, pengingat kuliah, aplikasi cuaca
- Unduh CV (PDF) langsung dari situs
- OG image & favicon kustom untuk preview link

## 🛠 Tech Stack

- **Framework:** Next.js 16 (App Router) + React 19
- **Bahasa:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animasi:** Framer Motion
- **Ikon:** lucide-react, react-icons
- **Hosting:** Vercel

## 🚀 Menjalankan Lokal

```bash
npm install
npm run dev
```

Buka http://localhost:3000.
